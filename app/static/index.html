Hướng dẫn AI Agent tích hợp API

POST /api/convert

Các AI Agent, autonomous script hoặc n8n/CrewAI có thể gọi trực tiếp endpoint HTTP để convert file PDF sang Markdown trong 1 bước:

cURL (Terminal / Bash tool) 
curl -X POST "http://localhost:8000/api/convert" \
  -F "file=@document.pdf" \
  -F "include_frontmatter=true" \
  -F "include_page_markers=true"
Python (Agent script) 
import requests

res = requests.post(
    "http://localhost:8000/api/convert",
    files={"file": open("doc.pdf", "rb")},
)
markdown = res.json()["markdown"]
print(f"Tokens: {res.json()['metadata']['estimated_tokens']}")
